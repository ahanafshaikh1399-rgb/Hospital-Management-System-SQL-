# Hospital-Management-System-SQL-
I’m excited to share my latest database project — a Hospital Management System designed to automate and streamline hospital operations using SQL.
This system focuses on improving operational efficiency, reducing manual work, and enhancing patient care through structured data management. 
🔹 Project Objective
The goal of this project was to develop a centralized system that manages hospital workflows including patient records, appointments, billing, and inventory while ensuring accurate and secure data handling. 
🔹 Key Modules Implemented
✔ Patient Management
✔ Doctor Management
✔ Appointments & Admissions
✔ Billing System
✔ Pharmacy Inventory
✔ Hospital Reporting
🔹 Database & SQL Concepts Used
🔸 Joins for relational data analysis
🔸 Aggregate functions for revenue and statistics
🔸 Subqueries for advanced insights
🔸 Window functions for ranking and analysis
🔸 Real-world healthcare database schema design
🔹 Key Insights Generated
📊 Identified most purchased medicines
📊 Calculated total hospital revenue
📊 Analyzed doctor appointment patterns
📊 Tracked room availability and patient discharge
🔹 Tools Used
💻 MySQL
🗄 Relational Database Design
📊 Data Analysis using SQL Queries
This project helped me strengthen my understanding of database design, SQL optimization, and real-world system modeling.
I’m excited to continue building more data-driven solutions in healthcare and analytics.
